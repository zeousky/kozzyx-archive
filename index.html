KozzyX

A little piece of server history. KozzyX brought moderation, anti-raid tools, tickets, and community commands together in one Discord bot.

Open the command guide ↓

What it did

  • Moderation

    Warnings, bans, timeouts, and a persistent case log.

  • Server setup

    Verification panels, anti-raid protection, and invite tracking.

  • Community tools

    Button tickets, giveaways, polls, reminders, and self-roles.

Command guide

/help
Browse commands by category.
/ban /warn
Apply a staff action and record it in the case log.
/server_setup
Run the guided setup for a server.
/verification setup
Set up a verification panel for new members.
/poll /selfroles
Let members vote or pick their own roles.
/data_request
Let server owners review the data stored for their server.
